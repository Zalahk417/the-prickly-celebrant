# Website photo catalogue

Keep full-resolution originals in a private Google Drive folder named Prickly Celebrant / Website Photos, with Events and Portraits subfolders. This is a recommended intake location; no Drive synchronisation is configured.

Website-ready copies live here permanently with the website source. Upload approved event photographs to events/ and portraits to portraits/. Use WebP/JPEG, meaningful filenames without spaces, about 1200px wide and preferably under 300 KB. Only upload pictures cleared for public website use.

Then add each file to catalogue.json under events or portraits, with src, alt and published: true. The website reads that catalogue; uploading a file alone does not publish it in the gallery. Ask Codex to optimise and register any batch. Published website images are public. Keep originals private and backed up.

Events feed the diagonal animated strips. Portraits crossfade every six seconds when two or more valid images exist. One image remains still. Broken images are skipped. The page honours reduced motion and has a pause button.

Real reviews require text, name, verified: true and published: true. Until then the moving cards are explicitly labelled sample wording. No invented rating is shown.
