# The Prickly Celebrant

Master website project for **The Prickly Celebrant**.

## Direction

An immersive, editorial, scroll-driven website built around the brand's cream / black / hot-red cactus identity.

Core interaction concept:
- a winding stone path descends through the page as the visitor scrolls
- stones, cactus artwork and doodles move at different depths
- service content appears as stops along the path
- red hand-drawn marks animate into view
- layered section transitions create one continuous illustrated world
- responsive behaviour is designed separately for desktop and mobile

## Stack

Plain HTML, CSS and JavaScript for maximum control and portability. No build step is required for the first version.

## Run locally

Open `index.html` or serve the repository with any static server.

## Deployment

The repository is intended to remain the editable source of truth. Production hosting can be connected later.
